# LayoutFox

Переключатель раскладки RU/EN для Windows и macOS. Исправляет слово, набранное не в той раскладке, на пробеле или прямо посреди слова; двойной Shift меняет раскладку и слово.

Здесь лежат только готовые сборки, код живёт отдельно. Программа сама проверяет этот репозиторий раз в шесть часов, скачивает новую версию и ставит её после вашего согласия.

## Установка

Скачайте файлы из [последнего релиза](https://github.com/danzerzine/LayoutFox-releases/releases/latest).

- **Windows:** `LayoutFox.exe`. Нужен .NET 8 Desktop Runtime. Положите exe в любую папку, где у вас есть право записи (не в Program Files), иначе обновление не сможет его заменить.
- **macOS 14+:** `LayoutFox-mac.zip`. Распакуйте и перенесите LayoutFox.app в «Программы». Приложение подписано собственным сертификатом, а не Apple, поэтому при первом запуске macOS его не откроет: зайдите в «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть». Потом дайте доступ в «Универсальном доступе».

`SHA256SUMS` содержит контрольные суммы файлов; программа сверяет с ними каждое обновление.
